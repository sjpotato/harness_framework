# PRD: YT 댓글 인사이트 (가칭)

## 목표
유튜브 영상 URL 하나만 입력하면 별도 설정 없이 댓글 감정분석과 크리에이터용 피드백을 즉시 리포트로 받아볼 수 있게 한다. "영상 올리고 댓글창을 스크롤하며 분위기를 파악하는" 데 드는 시간을, URL 붙여넣기 한 번으로 줄이는 것이 핵심 가치다.

## 사용자
- **주 사용자**: 구독자 규모와 무관하게 자기 채널을 혼자 운영하는 1인 크리에이터. 팀/매니저 없이 본인이 직접 댓글 반응을 확인한다.
- **사용 맥락**: 영상 업로드 직후 또는 정기적으로(주간 등) 반응을 체크할 때, 짧은 시간에 훑어보는 용도. 데스크톱 브라우저 사용을 기준으로 한다(모바일 최적화는 MVP 범위 밖 — 아래 "MVP 제외 사항" 참고).
- **사용자가 아닌 대상**: 여러 채널을 관리하는 MCN/에이전시, 팀 단위 협업이 필요한 조직 — 계정/권한 개념이 없으므로 해당 없음.

## 사용자 흐름
1. 앱 진입 → API 키(YouTube, Claude)가 저장돼 있지 않으면 설정 화면부터 노출(키 발급 방법 안내 포함), 저장돼 있으면 바로 URL 입력 화면으로 이동.
2. 유튜브 영상 URL 붙여넣기 → 분석 시작.
3. "댓글 수집 중..." 로딩 상태 표시(YouTube Data API 호출). 진행 중 "취소" 가능.
4. 수집 완료 후 "댓글 분석 중..." 로딩 상태로 전환(Claude API 호출). 진행 중 "취소" 가능.
5. 분석 완료 → 리포트 화면 표시(분석 대상 영상 제목/썸네일, 감정 비율, 핵심 테마, 대표 댓글, 강점/개선점, 분석 시각).
6. 다른 영상을 분석하려면 리포트/에러 화면 상단에 항상 떠 있는 URL 입력창에 새 URL을 붙여넣는다 — 뒤로가기나 화면 전환 없이 바로 재분석. 이전 리포트는 저장되지 않고 사라진다(의도된 동작, "MVP 제외 사항" 참고).
7. 화면 어디서든 상단의 설정 아이콘으로 API 키 화면에 돌아가 키를 바꾸거나 지울 수 있다.

## 핵심 기능

### 1. URL 입력 & 검증
- `youtube.com/watch?v=`, `youtu.be/`, `youtube.com/shorts/` 3가지 형식을 지원한다.
- `&t=30s`, `&list=...`처럼 타임스탬프/재생목록 파라미터가 함께 붙은 흔한 공유 링크도 `v` 파라미터만 정상 추출해 지원한다 — 부가 파라미터가 있다고 "지원하지 않는 URL"로 오분류하지 않는다.
- video ID를 추출할 수 없는 문자열(유튜브 URL이 아님, 재생목록/채널/커뮤니티 게시물/라이브 URL 등)은 "유효한 유튜브 영상 URL이 아닙니다" 안내와 함께 분석을 시작하지 않는다.
- 붙여넣기 직후 즉시 형식을 검증하며, 별도 "확인" 버튼 없이 오류를 바로 보여준다.
- 이 입력창은 URL 입력 화면뿐 아니라 리포트/에러 화면 상단에도 항상 떠 있어, 언제든 새 URL을 붙여넣어 재분석을 시작할 수 있다(사용자 흐름 6번 참고).

### 2. 댓글 수집
- 댓글을 가져오기 전에 YouTube Data API `videos.list`로 영상 존재 여부·공개 상태·댓글 활성화 여부와 함께 제목·썸네일을 먼저 확인한다(리포트 화면에 표시할 메타데이터도 이때 함께 확보 — "4. 리포트 화면" 참고).
- 이어서 `commentThreads.list`로 관련순(relevance) 상위 최대 100개(1페이지)를 수집한다.
- 대댓글(replies)은 수집하지 않는다 — 최상위 댓글만 분석 대상.
- 댓글 텍스트만 사용하고 작성자 식별 정보(채널명, 프로필 사진 등)는 수집·저장·리포트 노출을 하지 않는다 — 개인정보 최소 수집.
- 수집 중에는 "취소" 버튼을 노출한다. 취소 시 진행 중인 요청을 중단하고 URL 입력 화면으로 즉시 복귀한다(과금되는 Claude 호출 이전이므로 취소해도 비용 없음).

### 3. AI 감정분석 & 피드백 생성
- 수집한 댓글 전체를 Claude API에 전달해 다음을 생성한다:
  - 긍정/부정/중립 비율(%, 합계 100)과 각각의 실제 댓글 개수(예: "긍정 62개(71%)")
  - 자주 언급되는 핵심 테마 3~5개 (예: "편집 속도", "음질", "주제 선정")
  - 크리에이터가 잘하고 있는 점 (근거 댓글 포함)
  - 개선하면 좋을 점 (근거 댓글 포함)
  - 대표 댓글 인용 3~5개 (긍정/부정 균형 있게 선정)
- 댓글이 어떤 언어로 작성됐든 테마·피드백 등 생성되는 리포트 텍스트는 항상 한국어로 작성하도록 지시한다 — 사용자(크리에이터)가 읽는 언어 기준이며, 댓글 원문 인용 자체는 번역하지 않고 원문 그대로 보여준다.
- 도배/광고/링크만 있는 스팸성 댓글은 감정분석 대상에서 제외하도록 프롬프트로 지시한다(완전 차단을 보장하지는 않음 — "에러 케이스 & 엣지 케이스" 참고).
- 분석 중에도 "취소" 버튼을 노출한다. 단, 이미 전송된 Claude 요청 자체를 중간에 멈출 수는 없으므로(과금은 이미 발생) "취소"는 응답을 기다리지 않고 화면만 URL 입력으로 되돌리는 동작으로 안내한다.

### 4. 리포트 화면
- 상단에 분석 대상 영상의 제목·썸네일을 표시해 "지금 보고 있는 게 어떤 영상 리포트인지" 항상 확인 가능하게 한다.
- 리포트가 생성된 시각(예: "2026-09-01 14:32 기준")을 표기해, 댓글은 계속 늘어날 수 있으므로 이 리포트가 그 시점의 스냅샷임을 알린다.
- 감정 비율을 막대 또는 도넛 형태로 시각화하되, 색상만으로 구분하지 않고 항상 %와 라벨 텍스트를 함께 표기한다(색맹 등 색상 구분이 어려운 사용자 고려 — `docs/UI_GUIDE.md` 참고).
- 테마, 강점, 개선점을 구분된 리스트로 표시한다.
- 대표 댓글은 원문 그대로 인용한다(사용자 생성 콘텐츠이므로 XSS 방지 처리 필수 — `docs/ARCHITECTURE.md`, ADR-006 참고).
- 실제 수집 댓글 수(예: "총 87개 댓글 분석")를 리포트 상단에 표기해 표본 크기를 사용자가 인지하게 한다.
- 수집된 댓글이 5개 미만이면 "댓글 수가 적어 분석 결과의 신뢰도가 낮을 수 있습니다" 같은 caveat 문구를 리포트 상단에 함께 표시한다.
- 리포트 화면 상단에는 새 URL을 바로 입력할 수 있는 입력창과 설정 아이콘이 항상 떠 있다(사용자 흐름 6·7번 참고) — 다른 화면으로 이동해야만 재분석/설정 변경이 가능한 구조가 아니다.

### 5. API 키 설정
- YouTube Data API 키, Claude API 키 입력 필드 2개.
- 각 필드 옆에 "키 발급받기" 링크와 함께 발급 절차를 한두 문장으로 안내한다(Google Cloud Console에서 YouTube Data API v3 활성화, Anthropic Console에서 API 키 생성) — 대상 사용자가 개발자가 아닐 수 있으므로 첫 진입 장벽을 낮춘다.
- Claude API는 호출당 실제 요금이 부과된다는 점을 설정 화면에 한 줄로 고지한다(예: "분석 1회당 Anthropic 계정에 소액이 청구됩니다").
- 저장 시 빈 값 여부만 검증한다. 키가 실제로 유효한지는 첫 API 호출 시점에 확인한다.
- `localStorage`에 저장하며, "키 지우기" 버튼으로 언제든 삭제할 수 있다.
- 입력 필드는 비밀번호 형태로 마스킹하고, "표시" 토글로 값을 확인할 수 있게 한다.
- 최초 설정 이후에도 화면 상단 설정 아이콘을 통해 언제든 이 화면으로 돌아와 키를 변경/삭제할 수 있다.

## 에러 케이스 & 엣지 케이스
아래 각 케이스는 서로 다른 안내 문구로 사용자에게 표시해야 한다 — "오류가 발생했습니다"로 뭉뚱그리지 않는다(`docs/UI_GUIDE.md` 로딩/에러 상태 원칙 참고).

| 구분 | 케이스 | 기대 동작 |
|------|--------|-----------|
| 입력 | 유튜브 영상 URL이 아닌 문자열 | 분석 시작 전 즉시 안내, API 호출 없음 |
| 입력 | 재생목록/채널/커뮤니티 게시물/라이브 URL | "영상 URL만 지원합니다" 안내 |
| 입력 | 빈 입력으로 분석 시도 | 분석 버튼 비활성화 또는 즉시 안내 |
| 키 | YouTube/Claude 키 중 하나라도 미입력 | 분석 시작 전 설정 화면으로 유도 |
| 키 | YouTube API 키 형식 오류/무효 (403 keyInvalid) | "YouTube API 키를 확인해주세요" |
| 키 | Claude API 키 무효 (401) | "Claude API 키를 확인해주세요" |
| YouTube API | 쿼터 초과 (403 quotaExceeded) | "오늘 API 사용량을 초과했습니다. 내일 다시 시도하거나 다른 키를 사용하세요" |
| YouTube API | 영상이 존재하지 않음/삭제됨 (404 또는 빈 결과) | "영상을 찾을 수 없습니다" |
| YouTube API | 비공개/연령제한 영상 | "비공개이거나 접근이 제한된 영상은 분석할 수 없습니다" |
| YouTube API | 댓글 사용 중지된 영상 | "이 영상은 댓글이 비활성화되어 있습니다" |
| YouTube API | 댓글 0개 | "아직 댓글이 없습니다" — Claude 호출 자체를 생략 |
| YouTube API | 댓글이 100개 미만 (예: 12개) | 정상 진행하되 리포트에 실제 수집 개수를 표시해 표본이 적음을 인지시킴 |
| YouTube API | 네트워크 오류/타임아웃(10초) | "댓글을 불러오지 못했습니다. 다시 시도해주세요" + 재시도 버튼 |
| Claude API | 응답이 기대한 JSON 스키마와 다름(파싱 실패) | 1회 자동 재시도 후에도 실패하면 "분석 결과를 생성하지 못했습니다" 안내 |
| Claude API | rate limit / 과부하 (429/529) | "잠시 후 다시 시도해주세요" + 재시도 버튼 |
| Claude API | 네트워크 오류/타임아웃(30초) | 위와 동일 |
| 콘텐츠 | 댓글에 HTML/스크립트 태그, 이모지, 다국어 텍스트 혼재 | 원문 그대로 안전하게 이스케이프 후 표시(렌더링 시 실행되지 않아야 함) |
| 콘텐츠 | 스팸/도배성/광고 댓글이 다수 | Claude 프롬프트에서 분석 대상 제외를 지시하되, 완전 차단은 보장하지 않음을 인지 |
| 사용성 | 분석 도중 "분석 시작" 재클릭(중복 요청) | 진행 중에는 버튼 비활성화, 중복 호출 방지 |
| 사용성 | 수집/분석 도중 "취소" 클릭 | 진행 중인 요청을 중단하고 URL 입력 화면으로 즉시 복귀 |
| 사용성 | 분석 도중 새로고침/이탈 | 진행 상태는 저장되지 않으므로 처음부터 다시 시작(의도된 동작) |
| 콘텐츠 | 수집된 댓글이 5개 미만 | 정상 진행하되 리포트에 "표본이 적어 신뢰도가 낮을 수 있음" caveat 표시 |

## MVP 제외 사항
- 로그인/회원가입, 사용자 계정
- 서버/백엔드/DB — 완전한 프론트엔드 전용 SPA
- 리포트 저장·공유·히스토리(새로고침하면 사라짐)
- 여러 영상 비교, 채널 단위 통합 분석
- 댓글 100개 초과 수집을 위한 페이지네이션
- 대댓글(replies) 분석
- 모바일 반응형 최적화(데스크톱 우선, 레이아웃이 완전히 깨지지만 않으면 됨)
- 다국어 UI(한국어 고정)
- 댓글 실시간 갱신/자동 새로고침
- 스팸 댓글 완전 필터링 보장
- 자동 재시도/백오프(재시도는 사용자가 버튼을 눌러야 함 — ADR-009)

## 디자인
- 다크모드 고정. 마케팅 랜딩이 아니라 매일 켜보는 분석 도구처럼 보여야 한다.
- 무채색 기반 + 감정 시맨틱 컬러(긍정=초록, 부정=빨강, 중립=회색)만 포인트로 사용한다.
- AI 슬롭 안티패턴(글래스모피즘, 그라데이션 텍스트, 보라/인디고 브랜드 컬러 등) 금지 — 자세한 규칙은 `docs/UI_GUIDE.md` 참고.
